Growlog is a minimal, nature-themed productivity app which combines a focused checklist with a rich-text journal, featuring local browser persistence and smooth CSS animations, made to get work done.

Features:

Task Management

    Task Creation & Details: Add tasks with optional inline notes for extra context.

    Dynamic Task Segregation: Checking a task automatically disables its inputs, strikes through the text, and archives it into the Completed Tasks section.

    Interactive Deletion: Remove individual tasks with real-time list restructuring.

    Empty State Illustration: An animated, swaying seedling appears that motivates the user to add tasks and get work done when all tasks are clear.
---
Progress Dashboard

    Integrated directly inside the sidebar.

    Dynamically updates completion percentages and task counters (e.g., 2 of 5 tasks completed) in real time as items are added, checked, or deleted.
---
Rich-Text Journaling

    Multi-Entry Management: Create, view, switch, and delete journal entries through a pill-based navigation list.

    Rich-Text Editor: In-place text formatting using standard commands (Bold, Italic, Underline, Bullet Lists).

    Persistent Titles: Autosaves custom titles and entry bodies.
---
Local Persistence

    Full offline support powered by browser localStorage.

    Tasks, journal entries, active tab state, and progress metrics persist seamlessly across page refreshes.
